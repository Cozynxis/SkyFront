# SKYFRONT Spawn Island models

Upload these five GLB files **directly into this folder** using GitHub's Add file → Upload files. Keep the filenames unchanged:

- `small_modern_garage.glb`
- `small_grass_low_poly.glb`
- `low_poly_rock_set.glb`
- `stylized_bush.glb`
- `low-poly_tree.glb`

The game loads them automatically through `src/spawn-scenery.js`. Embedded materials and textures are preserved. No Python script or local install needed. GitHub's web upload may reject large files; if so use Git LFS or a local Git client.
